# PicTacticAgent - 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品名称
**PicTacticAgent** - AI 驱动的自媒体封面图生成器

### 1.2 产品定位
面向自媒体创作者（YouTube、B站、小红书等）的智能封面图生成工具，通过多 Agent 协作实现高质量、稳定的封面图批量生成。

### 1.3 目标用户
- 科技/AI 类自媒体博主
- YouTube/B站内容创作者
- 需要频繁制作封面图的自媒体运营者

---

## 2. 问题与痛点

### 2.1 痛点一：文生图模型随机性高
**现状**：
- 用户使用 DALL-E、Midjourney 等工具生成封面图
- 同一个提示词每次生成结果差异很大
- 用户需要开多个窗口，重复提交同一提示词
- 最后人工筛选，效率低下

**用户行为**：
```
打开多个标签页 → 输入相同提示词 → 等待生成 → 人工对比筛选 → 重复以上步骤
```

### 2.2 痛点二：缺乏风格参考和提示词优化
**现状**：
- 同领域优秀创作者的封面风格可以借鉴
- 用户不知道如何将参考图片的风格融入提示词
- 缺乏专业的提示词优化能力

**用户需求**：
- 上传参考图片，自动分析风格特征
- 基于分析结果增强原始提示词
- 生成与参考风格一致的封面图

---

## 3. 解决方案

### 3.1 核心理念
**"自动化批量生成 + 智能评估筛选 + 风格增强"**

用 AI Agent 替代人工的重复操作，实现：
1. 自动分析参考图片风格
2. 智能增强用户提示词
3. 批量生成多张候选图片
4. 自动评估并筛选最佳结果
5. 循环迭代直到满足质量要求

### 3.2 多 Agent 协作架构

```
┌─────────────────────────────────────────────────────────────┐
│                    用户输入                                  │
│  - 原始提示词："程序员在电脑前工作，科技感背景"              │
│  - 参考图片（可选）                                          │
│  - 配置：最大轮次、每轮数量、质量阈值                        │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│              Prompt Enhancement Agent                        │
│  - 分析参考图片的风格、颜色、布局                            │
│  - 增强原始提示词，添加专业描述                              │
│  输出："程序员在现代化办公室工作，蓝紫色科技光效，            │
│        极简构图，暗色调背景，4K超清，电影级光影"             │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│              Image Generation Agent                          │
│  - 调用文生图 API（DALL-E 3、SDXL等）                        │
│  - 每轮批量生成 5-10 张图片                                  │
│  - 支持并行调用多个模型                                      │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                   Review Agent                               │
│  - 多维度评估图片质量（匹配度、美观度、技术质量）            │
│  - 对图片进行评分排序                                        │
│  - 决策：是否满足质量要求？                                  │
│    - 满足 → 输出最佳图片                                     │
│    - 不满足 → 返回改进建议，进入下一轮                       │
└─────────────────────────────────────────────────────────────┘
                              │
                    ┌─────────┴─────────┐
                    │                   │
               满足阈值            未满足阈值
                    │                   │
                    ▼                   ▼
            输出最佳图片          继续下一轮生成
                               （最多 N 轮）
```

## 5. 非功能需求

### 5.1 性能要求
- 单轮生成（5张图）完成时间 < 60秒
- 页面加载时间 < 3秒
- 支持同时处理 10 个生成任务

### 5.2 可用性要求
- 服务可用性 > 99%
- API 调用失败自动重试
- 任务中断可恢复

### 5.3 安全要求
- API Key 安全存储
- 用户上传图片病毒扫描
- 生成内容合规检查

## 6. 用户流程

### 6.1 基础流程
```
1. 用户打开应用
2. 输入封面描述："我想要一个科技感的AI主题封面"
3. （可选）上传 1-3 张参考图片
4. 点击"开始生成"
5. 系统显示：
   - 正在分析参考图片...
   - 增强后的提示词：xxx
   - 第 1 轮生成中... (3/5)
   - 评估中...
   - 最高分 0.65，未达阈值，开始第 2 轮...
   - 第 2 轮生成中... (5/5)
   - 评估中...
   - 最高分 0.82，已达阈值！
6. 展示结果画廊，最佳图片置顶
7. 用户下载满意的图片
```

### 6.2 进阶流程（自定义配置）
```
1. 用户调整配置：
   - 最大轮次：5
   - 每轮数量：8
   - 质量阈值：0.85
   - 模型：DALL-E 3 + SDXL
2. 开始生成
3. 中途查看进度，发现第 3 轮已有满意结果
4. 点击"提前结束"
5. 查看并下载结果
```

## 8. 成功指标

### 8.1 核心指标
| 指标 | 目标值 | 说明 |
|------|--------|------|
| 首次达标率 | > 60% | 第一轮生成即达到质量阈值的比例 |
| 平均轮次 | < 2.5 | 达到质量要求的平均生成轮次 |
| 用户满意度 | > 80% | 用户对最终结果的满意比例 |

### 8.2 效率指标
| 指标 | 目标值 | 说明 |
|------|--------|------|
| 相比手动效率提升 | > 3x | 与用户手动多次生成对比 |
| 单次生成时间 | < 2分钟 | 从开始到获得满意结果 |

## 9. 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| API 调用成本高 | 高 | 实现智能策略，减少无效生成 |
| 评分不准确导致循环过多 | 中 | 多维度评分 + 人工校准 |
| API 限流或不稳定 | 中 | 多服务商备份 + 重试机制 |
| 生成内容违规 | 高 | 接入内容审核 API |
