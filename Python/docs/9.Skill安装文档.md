# MediaCrawlerPro Skill 安装文档

本文档面向 **AI Coding Agent**（如 Claude Code、Cursor、Windsurf 等），说明如何安装和使用 MediaCrawlerPro Skill，使 AI Agent 具备自媒体数据爬取能力。

## 什么是 Skill

Skill 是一组结构化的 Markdown 指令文件（`SKILL.md` + reference 文件），安装到 AI Agent 的配置目录后，Agent 能自动识别用户的爬虫需求并按照 Skill 中的流程执行。

### Skill 文件结构

```
.claude/skills/media-crawler-pro/
├── SKILL.md                        # 主入口文件（路由决策 + 快速命令模板）
└── references/                     # 按需加载的详细文档
    ├── setup.md                    # 环境安装与服务启动指南
    ├── cookie-preflight.md         # Cookie 准备、验证与故障排查
    ├── cookie-bridge.md            # CookieBridge API 详细指南
    ├── downloader.md               # DownloadServer API 详细指南
    ├── text-crawler.md             # Python 文本爬虫详细用法
    ├── platforms.md                # 各平台 URL/ID 格式参考
    ├── sqlite-tables.md            # SQLite 数据库表结构参考
    └── sentiment-analysis.md       # 评论舆情分析流程
```

## 前置条件（请先完成再安装）

### 1. GitHub 仓库访问权限

> **重要**：MediaCrawlerPro 所有仓库均为**私有仓库**，必须是组织邀请的成员才能访问。如果你直接 `git clone` 遇到 404 错误，说明你的 GitHub 账户没有访问权限。

**确认步骤**：

```bash
# 测试是否有仓库访问权限（应返回仓库信息，而非 404）
gh repo view MediaCrawlerPro/MediaCrawlerPro-Python --json name 2>&1

# 如果返回 404 或权限错误，请联系组织管理员获取邀请
# 如果是 SSH 认证问题，确认 SSH key 已配置：
ssh -T git@github.com
```

**常见问题**：
- `404 Not Found`：你的 GitHub 账号未被邀请加入组织，请联系管理员
- `Permission denied (publickey)`：本地 SSH key 未配置或未添加到 GitHub，参考 [GitHub SSH 配置文档](https://docs.github.com/en/authentication/connecting-to-github-with-ssh)
- `could not read Username`：Git 凭据未配置，建议使用 `gh auth login` 完成认证

### 2. 系统依赖安装

```bash
# uv 包管理器（用于管理 Python 环境和依赖）
# 如果未安装：curl -LsSf https://astral.sh/uv/install.sh | sh
uv --version

# Node.js（SignSrv 签名服务需要）
node --version

# Chrome 浏览器（CookieBridge 需要，可选）
```

### 3. 克隆子项目

所有子项目应位于同一个父目录下（即 `$MCR_ROOT`）：

```bash
# 创建并进入项目根目录
mkdir -p ~/MediaCrawlerPro && cd ~/MediaCrawlerPro

# 克隆必需子项目
git clone git@github.com:MediaCrawlerPro/MediaCrawlerPro-SignSrv.git
git clone git@github.com:MediaCrawlerPro/MediaCrawlerPro-Python.git

# 克隆可选子项目（按需）
git clone git@github.com:MediaCrawlerPro/MediaCrawlerPro-Downloader.git
git clone git@github.com:MediaCrawlerPro/MediaCrawlerPro-CookieBridge.git
```

> 如果 `git clone` 遇到 404，请回到步骤 1 确认仓库访问权限。

### 4. 安装各子项目依赖

进入对应子项目执行 `uv sync` 即可，uv 会按项目配置自动准备 Python 环境和依赖。

```bash
MCR_ROOT=~/MediaCrawlerPro

# SignSrv（必需）
cd "$MCR_ROOT/MediaCrawlerPro-SignSrv" && uv sync

# Python 爬虫（必需）
cd "$MCR_ROOT/MediaCrawlerPro-Python" && uv sync

# Downloader（可选）
cd "$MCR_ROOT/MediaCrawlerPro-Downloader/DownloadServer" && uv sync

# CookieBridge（推荐）
cd "$MCR_ROOT/MediaCrawlerPro-CookieBridge/server" && uv sync
```

### 子项目说明

| 子项目 | 用途 | 必需 |
|--------|------|------|
| MediaCrawlerPro-SignSrv | 签名服务 | 是 |
| MediaCrawlerPro-Python | 文本数据爬虫 | 是 |
| MediaCrawlerPro-Downloader | 视频/图片下载 | 按需 |
| MediaCrawlerPro-CookieBridge | Cookie 自动同步 | 推荐 |

## 安装方式一：Claude Code

Claude Code 使用 `~/.claude/skills/` 目录管理 Skills。

### 方法 A：复制安装（推荐）

```bash
# 确定 Skill 源目录（本仓库中的 .claude/skills/media-crawler-pro）
SKILL_SRC="$(git rev-parse --show-toplevel)/.claude/skills/media-crawler-pro"

# 复制到 Claude Code 的 skills 目录
mkdir -p ~/.claude/skills/media-crawler-pro/references
cp "$SKILL_SRC/SKILL.md" ~/.claude/skills/media-crawler-pro/
cp "$SKILL_SRC/references/"*.md ~/.claude/skills/media-crawler-pro/references/
```

### 方法 B：符号链接安装

```bash
SKILL_SRC="$(git rev-parse --show-toplevel)/.claude/skills/media-crawler-pro"
ln -sf "$SKILL_SRC" ~/.claude/skills/media-crawler-pro
```

符号链接的好处是仓库更新 Skill 后自动生效，无需重新复制。

### 方法 C：通过 Claude Code Settings UI 安装

1. 打开 Claude Code 设置：`/settings`
2. 找到 Skills 配置项
3. 添加新 Skill，name 填 `media-crawler-pro`
4. 将 `SKILL.md` 的内容粘贴到 Skill 配置中

## 安装方式二：Cursor / 其他 AI IDE

Cursor 等 AI IDE 支持项目级别的 Agent 指令文件。

### Cursor

将 `SKILL.md` 内容复制到项目根目录的 `.cursor/rules/media-crawler-pro.md` 中：

```bash
SKILL_SRC="$(git rev-parse --show-toplevel)/.claude/skills/media-crawler-pro"
mkdir -p .cursor/rules
cp "$SKILL_SRC/SKILL.md" .cursor/rules/media-crawler-pro.md
# reference 文件需要内联到主文件中，或放到 .cursor/rules/ 下
```

### Windsurf / 通用方案

大多数 AI IDE 支持在项目根目录放置指令文件（如 `.ai/instructions.md`），具体格式参考各 IDE 文档。核心文件是 `SKILL.md`，reference 文件按需引用。

3. 启动必要服务

## 自定义与扩展

### 修改默认配置

Skill 中的默认配置（如 Cookie 来源、并发数）可在以下文件中调整：

```
$MCR_ROOT/MediaCrawlerPro-Python/config/base_config.py
```

关键配置项：
- `ACCOUNT_POOL_SAVE_TYPE`：Cookie 来源（`cookie_bridge` / `xlsx` / `mysql`）
- `MAX_CONCURRENCY_NUM`：并发数（默认 1，勿调高）
- `CRAWLER_TIME_SLEEP`：请求间隔秒数（默认 1）
- `CRAWLER_MAX_NOTES_COUNT`：搜索最大爬取数量（默认 40）

### 添加新的 reference 文件

在 `.claude/skills/media-crawler-pro/references/` 目录下添加新的 `.md` 文件，并在 `SKILL.md` 中引用即可。
