# Content Remix Agent 产品功能介绍文档

## 一、产品概述

**Content Remix Agent（内容二创助手）** 是一款 AI 驱动的内容创作灵感工具。用户只需粘贴小红书、抖音、B站、快手的内容链接，系统即可自动完成内容提取、结构拆解、爆款分析，并生成创作灵感和文案建议。

**产品定位**：帮助内容创作者学习、借鉴优秀内容的创作技巧，激发原创灵感，而非简单复制抄袭。

---

## 二、目标用户

| 用户类型 | 使用场景 |
|---------|---------|
| **内容创作者** | 快速学习爆款内容的创作技巧，获取原创灵感 |
| **新媒体运营** | 分析竞品内容，提炼可复用的内容框架 |
| **内容学习者** | 拆解优质内容，系统学习创作方法论 |

---

## 三、支持平台

| 平台 | 内容类型 | 链接示例 |
|------|---------|---------|
| 小红书 | 图文笔记、视频笔记 | `xhslink.com/xxx` 或完整链接 |
| 抖音 | 短视频 | `v.douyin.com/xxx` |
| B站 | 视频 | `bilibili.com/video/BVxxx` 或 `b23.tv/xxx` |
| 快手 | 短视频 | `v.kuaishou.com/xxx` |

支持长链接和短链接，系统会自动识别平台并解析。

## 四、核心功能

### 4.1 四种学习模式

用户可根据需求选择不同的学习模式：

| 模式 | 名称 | 功能说明 | 适用场景 |
|------|------|---------|---------|
| **精华提炼** | summarize | 快速提炼内容核心要点，生成精简版本 | 快速掌握精华，节省时间 |
| **深度拆解** | analyze | 以教学视角分析内容，解释创作技巧原理 | 系统学习方法论，理解"为什么好" |
| **模板学习** | template | 提取可复用的创作模板和内容框架 | 应用到自己的原创主题 |
| **风格探索** | style_explore | 同话题不同风格的多个参考版本 | 探索适合自己的表达方式 |

### 4.2 内容分析报告

系统对内容进行全面分析，输出结构化报告：

**① 基本信息卡片**
- 内容封面、标题、作者
- 互动数据（点赞、收藏、评论数）

**② 内容摘要**
- 1-2 句话概括内容核心

**③ 结构拆解**
- 分段分析（开头钩子、痛点引入、解决方案、效果展示、行动号召等）
- 视频内容显示时间段对应
- 每段使用的创作技巧

**④ 爆款元素识别**
- 前3秒钩子
- 痛点共鸣
- 悬念设置
- 情绪调动
- 价值承诺
- 行动号召
- 视觉冲击
- 节奏把控

**⑤ 可借鉴点**
- 3-5 个可以应用到自己创作的技巧

**⑥ 风格标签**
- 内容的风格定位（如：干货型、种草型、故事型等）

### 4.3 创作灵感生成

**① 标题建议**
- 提供 3 个不同风格的标题参考（数字型、悬念型、痛点型等）

**② 开头钩子**
- 提供 3 个不同类型的开头示例（反问式、故事式、数据式等）

**③ 内容框架**
- 可直接使用的创作结构模板

**④ 灵感内容**
- 完整的创作灵感参考（Markdown 格式）
- 支持一键复制

### 4.4 对话式交互

- **追问调整**：可以继续对话，要求修改标题、调整风格、重新生成等
- **上下文感知**：系统记得之前的分析结果，支持连续对话
- **实时反馈**：流式输出，实时显示处理进度

### 4.5 会话管理

- **历史记录**：保存所有分析会话，随时回看
- **会话搜索**：快速查找历史分析
- **会话管理**：支持新建、删除会话

## 五、用户操作流程

### 5.1 标准流程

```
1. 进入应用，看到欢迎页面
   ↓
2. 选择快速操作（精华提炼/深度拆解/模板学习/风格探索）
   或 直接在输入框粘贴链接
   ↓
3. 系统自动处理，实时显示进度：
   - 解析链接
   - 获取内容
   - 视频转文字（如有视频）
   - AI 分析生成
   ↓
4. 查看分析报告和创作灵感
   ↓
5. 可继续对话追问或调整
```

### 5.2 处理进度展示

在处理过程中，用户可以看到：

| 步骤 | 说明 |
|------|------|
| ✓ 已提取笔记链接 | 识别平台和内容 ID |
| ✓ 已完成解析链接 | 获取标题、视频等资源 |
| ✓ 已获取原始内容 | 视频下载和语音转文字（如适用） |
| ⟳ 结构拆解生成 执行中... | AI 正在分析 |
| ○ 生成灵感 | 等待执行 |

### 5.3 追问示例

```
用户: 分析 https://v.douyin.com/xxx

系统: [完成分析报告 + 创作灵感]

用户: 换一个更短的标题

系统: 好的，这里有几个更简短有力的标题版本...

用户: 能不能用更轻松幽默的风格改写？

系统: 没问题，这是轻松幽默风格的版本...
```

## 六、输出示例

```

【内容摘要】
这是一个职场效率类视频，用3个简单技巧帮助打工人提升日常工作效率。

【结构拆解】
┌─────────────────────────────────────────────┐
│ 时间段    │ 内容模块   │ 使用技巧         │
├─────────────────────────────────────────────┤
│ 0:00-0:03 │ 开场钩子   │ 反问句引发共鸣   │
│ 0:03-0:10 │ 痛点引入   │ 场景化描述       │
│ 0:10-0:45 │ 核心方法   │ 数字化分步骤     │
│ 0:45-0:55 │ 效果展示   │ 前后对比         │

【爆款元素】
✓ 前3秒钩子强 - 使用反问句 "你是不是也..."

• 内容框架: 痛点→方案→效果 的经典三段式
```

## 七、产品价值

1. **节省时间** - 自动提取和分析，无需手动记录
2. **系统学习** - 结构化拆解，理解爆款背后的逻辑
3. **激发灵感** - 提供多种角度的创作参考
4. **持续优化** - 对话式交互，随时调整输出
5. **原创导向** - 强调学习和借鉴，而非复制抄袭

---

## 八、使用限制

- 仅支持小红书、抖音、B站、快手四个平台
- 视频内容需要一定处理时间（视频越长时间越久）
- AI 生成内容仅供参考，建议结合自身特点进行原创
